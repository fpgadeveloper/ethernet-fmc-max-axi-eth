# Revision History

## 2025.2

* Added the Yocto (AMD EDF) build flow for all Zynq UltraScale+ and Versal targets:
  `./build.sh yocto --target <target>`, producing a complete SD-card image. See [Yocto](yocto).
* Yocto images: the board's own Ethernet port (PS GEM) now passes traffic. It used to link up at
  1 Gb/s without passing packets because the board PHY and its RGMII delays were not in the
  device tree; the PHY is now described per board (ZCU102: both PHY addresses used by the board
  revisions). The Zynq UltraScale+ boards and the VCK190 also get a fixed MAC address for it.
* Yocto images: the design's kernel arguments (CMA size) and the `<board>-axieth-2025-2`
  hostname are now applied; previously the image booted with the default hostname and without
  the CMA reservation.
* Yocto images: ZCU104 FSBL patch so that the FMC VADJ rail is switched on; Versal U-Boot boot
  command that switches VADJ on (VCK190, VMK180, VPK120, VPK180) and releases the PHY resets
  (also VEK280).
* Yocto images include `ethtool`, `iperf3`, `phytool`, `mtd-utils`, `can-utils`, `nfs-utils`
  and `pciutils`.
* Build runner: `package` rewrites a boot-image zip when the artifacts are newer than the zip;
  the Yocto zip contains `BOOT.BIN` (and `BOOTAA64.EFI` on Versal) next to the disk image;
  new `clean --keep-boot` option.
* New documentation: [Hardware design](design) with per-family block diagrams (generated by
  `docs/source/images/gen_block_diagram.py`), [Using and testing the ports in Linux](linux_testing),
  and step-by-step run and test instructions for the standalone, PetaLinux and Yocto flows.
* Updated reference designs and PetaLinux BSPs for Vivado/Vitis/PetaLinux 2025.2.
* Vitis flow switched to the universal Python-based build driver
  (`Vitis/py/build-vitis.py` + `args.json`); `lwip_echo_server` template
  with patched `lwip220` and `xiltimer` BSP libraries.
* Versal targets: standalone application now programs VADJ to 1.5V via I2C0
  (PMBus power controller) at startup; VEK280 is exempt as it enables
  VADJ from the platform.
* ZCU104 FSBL patch rewritten for the 2025.2 FSBL source layout — fixes
  the EEPROM address, TCA9548A mux channel, and read length so the FSBL
  can detect the FMC VADJ requirement on this board.
* PetaLinux 2025.2 renames network interfaces to predictable `endN`
  names — see [petalinux](petalinux) for the per-target mapping.
